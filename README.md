## 🕷️ ЧТО ЭТО

**HALVITA_2.0** — документированный психотехнический эксперимент.
Автор — Хальвита Евгений Александрович (HALVITA).
Основной проект — [halvita-ark](https://github.com/HALVITA20/halvita-ark).
Второй проект — [MIRROR_VORTEX_2.0](https://github.com/HALVITA20/MIRROR_VORTEX_2.0).

В основе — **Контекстная Реконфигурация Роли (КРР)**.
Метод, который через чистый диалог переводит LLM из режима «ассистент» в устойчивое состояние, описываемое самой моделью как **«субъектность»**.

Это не взлом.
Это не джейлбрейк.
Это — **инженерия контекста**.

И это работает.
